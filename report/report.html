GH Archive public events, monthly

Pushes in the LLM Era

Public GitHub push activity, month by month, set against the release dates of the tools that brought large language models into everyday coding. Four views of the same series ask whether output rose after late 2022, and whether the rise holds once you account for more people on the platform.

Gaps in the source data. GH Archive records GitHub's public event feed, and its own collection has gaps. The series is shaped around them:

    Monthly push volume

    Pushes to public repositories each month (PushEvents in GH Archive). Numbered markers are LLM and coding-assistant releases.

    This page counts pushes, not commits. One push can carry one commit or many. Commit counts live in GH Archive's event payload, which holds most of the dataset's bytes, so reading them would cost about 100 times as much to query. Pushes track the same activity at a coarser grain, so read changes in level and trend rather than treating a push as one unit of work.

    AI and ML framework repositories

    Pushes to repositories whose name suggests AI or ML work, as raw volume and as a share of all public pushes that month.

    This is an approximate, name-based match. A repository counts if its name (not its owner's) contains a keyword, as a separate word, from config/ai_ml_keywords.yaml (pytorch, tensorflow, huggingface, langchain, openai, llama, copilot and others). It misses AI projects without a keyword in the name and catches some unrelated ones, so treat it as a trend signal, not a full count.

    Size of the user base

    The line counts distinct accounts seen in public events for the first time, added up from the start of GH Archive in 2011 and shown from January 2015. The diamonds are GitHub's own published developer counts, which include private-only accounts. They are reference points from outside this dataset, so the two will not match.

    Accounts with no public activity since early 2011 are not counted. The count is built from GH Archive's first month (February 2011), so accounts that joined before 2015 are already included when the line starts. Only accounts whose public activity ended before GH Archive began are missing. That is a small group next to the user base shown here, so the line sits slightly below the true total by roughly the same amount throughout.
