GitHub Innovation Graph · quarterly

GitHub in the LLM Era

How much code developers push to public GitHub repositories each quarter, measured against the trend before ChatGPT. The source is GitHub's own Innovation Graph, which leaves out bots and accounts too active to be one person.

What the data shows

    How far to trust this.

    • Public activity only. Private repositories, where most company code lives, are not counted.
    • An AI agent that pushes through a person's own account counts as that person's pushes, so the rise from 2025 likely includes work done by agents. That is arguably the effect being measured, but it is not the same as people doing more work.
    • The pre-ChatGPT baseline is only 12 quarters (2020 to 2022) and includes the 2020 lockdown surge, so the trend line is an approximate yardstick.
    • GitHub documents no change of method, and earlier quarters are identical in every release since January 2025. A change to GitHub's own bot filter could not be ruled out from outside.
    • Figures are sums over economies. GitHub withholds an economy's number when fewer than 100 developers did that activity, so the totals run slightly low.

    More developers, or more per developer?

    Developer accounts grow steadily, a little faster from 2025. Pushes per account fell through 2024 and then rose sharply, so most of the 2025 rise is not explained by more people joining.

    Developer accounts

    Accounts as of the end of each quarter, bots and spam excluded. Includes accounts that are no longer active.

    Developers pushing to AI-tagged repositories

    Developers who pushed at least once that quarter to a repository its owner tagged with each topic. A developer working in several tagged repositories counts once per topic.

    Topic tags are optional and set by repository owners, so these counts cover only tagged repositories and run low. Per-economy counts under 100 are withheld, which hides a topic entirely in its early quarters. Read the timing and shape, not the totals.

    Language mix

    Each language's share of developers pushing to repositories in it, for the languages most used in the latest quarter. A developer counts once for every language they push to, so shares are of developer–language pairs and add up to less than 100% across the languages shown.
