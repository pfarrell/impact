Commits in the LLM Era

Public GitHub commit activity, month by month, set against the release dates of the tools that brought large language models into everyday coding. Four views of the same series ask whether output rose after late 2022, and whether the rise holds once you account for more people on the platform.

Placeholder data: these numbers are synthetic

Every figure on this page comes from a made-up dataset built to test the charts. The BigQuery backfill has not been run yet. Do not cite or draw conclusions from any value here. The milestone dates and GitHub user counts are real reference points; everything derived from GH Archive is not.

Language mix

Each language's share of the month's commits, by the repository's primary language. Languages outside the top group fold into "Other languages".

Coverage gets weaker in recent years. Languages come from bigquery-public-data.github_repos, a static snapshot that has not been kept current. Repositories created after that snapshot have no language on record and land in "Unknown", so the Unknown band grows over time.

Read recent-year shares as directional, weaker than earlier years, rather than as exact.

AI and ML framework repositories

Commits to repositories whose name suggests AI or ML work, as raw volume and as a share of all public commits that month.

This is an approximate, name-based match. A repository counts if its name contains a keyword from config/ai_ml_keywords.yaml (pytorch, tensorflow, huggingface, langchain, openai, llama, copilot and others). It misses AI projects without a keyword in the name and catches some unrelated ones, so treat it as a trend signal, not a full count.

Size of the user base

The line counts distinct accounts seen in public events for the first time, added up from January 2015. The diamonds are GitHub's own published developer counts, which include private-only accounts. They are reference points from outside this dataset, so the two will not match.

Accounts first active before 2015 are never counted. The line only adds an account in the month it first appears, and only from January 2015 on. Anyone whose first public activity came earlier is left out at every point in the series, so the line sits below the true user base by a fixed amount throughout, not only in the early years.
